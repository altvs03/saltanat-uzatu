# Арұжан — Қыз ұзату | электронды шақыру

Одностраничный адаптивный сайт-приглашение в казахском национальном стиле.
Чистый HTML/CSS/JS, без сборки — готов к публикации на GitHub Pages.

## Структура

```
index.html        разметка всех 7 секций
css/style.css      стили, анимации, адаптивность
js/config.js       ЕДИНСТВЕННЫЙ файл, который обычно нужно редактировать —
                    имя, дата, время, место, ссылка на карту, WhatsApp, музыка, фото
js/main.js         логика: подстановка текста, плавные появления, параллакс,
                    Ken Burns, кнопка музыки, форма RSVP
images/            ваши фотографии (см. images/README.md)
audio/             фоновая музыка (см. audio/README.md)
```

## Как изменить содержимое

Откройте `js/config.js` и впишите свои значения (имя, дату, время, зал, адрес).
Меняются только строки в кавычках — остальной код трогать не нужно.

## Как добавить фотографии

Положите файлы в папку `images/` с именами, указанными в `images/README.md`
(или поменяйте пути в `js/config.js`). Пока фото нет — на их месте элегантная
бордово-золотая заглушка, сайт не ломается.

## Как проверить локально

Проще всего запустить встроенный сервер без установки чего-либо
(двойной клик на `index.html` не всегда корректно подгружает шрифты/фото):

```powershell
powershell -ExecutionPolicy Bypass -File scripts\serve.ps1
```

и открыть в браузере `http://localhost:8080`.

## Публикация на GitHub Pages

1. Создайте репозиторий и загрузите в него все файлы этой папки.
2. В настройках репозитория откройте **Settings → Pages**.
3. В качестве источника выберите ветку `main` и папку `/root`.
4. Через минуту сайт будет доступен по ссылке вида
   `https://<ваш-логин>.github.io/<репозиторий>/`.

## RSVP-форма

Форма работает без сервера: после отправки гость видит красивое сообщение
«Келетініңізге қуаныштымыз!». Если в `config.rsvpWhatsapp` указать номер
организатора (в формате `77001234567`), при отправке дополнительно откроется
WhatsApp с готовым текстом заявки — это самый простой способ получать
отклики без бэкенда.
